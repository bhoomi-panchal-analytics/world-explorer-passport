# 🌍 World Explorer Passport

An interactive educational geography app inspired by childhood travel explorer kits.  
Built using **Python**, **Streamlit**, and **GitHub**, this project transforms world exploration into a digital passport experience.

Users can explore countries, collect passport stamps, learn currencies and languages, and test their knowledge through interactive quizzes.

---

# ✈️ Inspiration

As a child, I had a travel-themed educational kit with:
- A large world map
- A toy passport
- Country stamps
- Currency and flag stickers
- Flashcards with facts about countries and cultures

That experience sparked my curiosity about:
- Languages
- Geography
- Cultures
- History
- Global systems

This project is a modern digital version of that experience.

---

# 🚀 Features

## 🌎 Country Explorer
Explore countries around the world and learn:
- Capital city
- Currency
- Languages
- Population
- Region
- National flag
- Fun facts

---

## 🛂 Digital Passport System
Users can:
- “Visit” countries
- Collect digital passport stamps
- Track exploration progress
- Build a virtual travel history

---

## 🧠 Interactive Quiz System
Challenge yourself with:
- Flag quizzes
- Capital city quizzes
- Currency quizzes
- Language quizzes

Track your score and improve your global knowledge.

---

## 🗺️ Interactive World Exploration
Navigate through:
- Countries
- Continents
- Regions
- Cultural information

Built with simple and clean UI principles for accessibility and usability.
